# EDUWAY — Study Abroad Agency

**Brand personality:** Young, optimistic, international, trustworthy.

## Design System

| Token | HEX | RGB |
|---|---|---|
| Primary | `#155EEF` | `rgb(21, 94, 239)` |
| Secondary | `#0B4BB3` | `rgb(11, 75, 179)` |
| Background | `#F8FAFF` | `rgb(248, 250, 255)` |
| Surface | `#EAF1FF` | `rgb(234, 241, 255)` |
| Text | `#15233A` | `rgb(21, 35, 58)` |
| Muted Text | `#667085` | `rgb(102, 112, 133)` |
| Accent | `#F79009` | `rgb(247, 144, 9)` |
| Accent Light | `#FFE2B8` | `rgb(255, 226, 184)` |

## Usage Rules

- Blue should dominate the brand.
- Orange is reserved for highlights, important CTAs and small visual accents.
- **60%** Background/neutral · **30%** Primary/Secondary · **10%** Accent.
